# 彩號研究所

以台灣彩券歷史開獎資料製作的靜態統計網站，目前以今彩 539 為主要分析項目。

## 功能

- 提供今彩 539、大樂透、威力彩、3 星彩、4 星彩與 BINGO BINGO 遊戲入口。
- 自動讀取今彩 539 歷史開獎資料並統計號碼出現次數。
- 顯示歷年出現最多的 5 個號碼與出現最少的 5 個號碼。
- 顯示統計期數與資料涵蓋日期。
- 支援桌面與行動裝置瀏覽。
- 透過 GitHub Actions 定期更新資料並部署至 GitHub Pages。

## 資料來源

開獎資料來自[台灣彩券官方網站－歷史各期獎號與開獎結果](https://www.taiwanlottery.com/lotto/history/result_download/)，由專案內的資料收集程式下載並整理為 CSV 格式。

歷史開獎次數不代表未來中獎機率；每次開獎皆為獨立隨機事件，本專案僅供數據研究與娛樂參考。
