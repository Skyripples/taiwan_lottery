# 台彩研究所

以台灣彩券遊戲為主題的資料研究網站，提供多款遊戲的歷史資料分析與選號功能。

## 主要功能

- 今彩 539、大樂透、威力彩、39 樂合彩、49 樂合彩、3 星彩與 4 星彩的歷史冷熱號碼及特殊規則統計，可切換全部、最近 30、60、120 期。
- 今彩 539 特殊號碼規則分析。
- 今彩 539 智慧選號，一次產生 10 組不同策略的參考號碼，並提供各策略的逐期歷史回測。
- 今彩 539、大樂透、威力彩、3 星彩、4 星彩、39 樂合彩及 49 樂合彩隨機選號。
- 提供各遊戲玩法、單注金額與獎金說明。
- 官方歷史資料定期自動更新，更新完成後自動部署至 GitHub Pages。

## 資料來源

今彩 539、大樂透、威力彩、39 樂合彩、49 樂合彩、3 星彩與 4 星彩的歷史開獎資料來自[台灣彩券官方歷史資料下載頁](https://www.taiwanlottery.com/lotto/history/result_download/)及官方近期開獎 API，由專案的資料收集程式整理、驗證並輸出為 CSV 資料。

網站分析結果與選號功能僅供資料研究及娛樂參考，不代表未來中獎機率。
